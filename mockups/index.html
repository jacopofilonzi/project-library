Project Library — mockup

Tutti i mockup navigano lo stesso albero (quello reale di ~/Development, incluso il caso annidato local/UNI/Ingegneria del Software/BuildPatternDemo) e partono da github/jacopofilonzi. Prova a cercare "bot" per vedere la ricerca locale e l'opzione "cerca ovunque".

  1. 09Colonne v2 (base scelta)La 01 con "Apri con" (split button + dropdown), info git reali e README caricato. Le colonne si adattano alla larghezza, minimo 2 colonne + scheda.
  2. 01ColonneVista a colonne (stile Finder), scheda dettaglio a destra, chip di scope nella ricerca.
  3. 02Spotlight a tokenSolo tastiera: le cartelle sono token nella barra, ⌫ risale, ultima riga "cerca ovunque".
  4. 03Path barTutto monospace in stile editor. Il path è l'input: / entra, Tab completa, **/ cerca ovunque. Anteprima a destra.
  5. 04StrumentoModuli stile hardware: display LCD con switch QUI/OVUNQUE, tasti fisici per i launcher.
  6. 05TipograficoNome della cartella gigante in serif, righe grandi, azioni al passaggio del mouse, ricerca in una barra fissa in basso.
  7. 06BentoCartelle come tile dimensionate in base a quanti progetti contengono, progetti come card.
  8. 07Split + READMESidebar colorata navigabile da tastiera e pagina README del progetto con i launcher in alto.
  9. 08CassettoMetafora fisica: cartelle manila e schede. Più giocoso.

Comuni a tutti: ⌫ con la ricerca vuota risale di una cartella · Ctrl ↵ cerca ovunque · Esc pulisce. Le azioni di apertura mostrano solo un avviso.
